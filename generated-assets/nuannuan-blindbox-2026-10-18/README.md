# 暖暖潮玩盲盒 · 公仔与包装

依据既有苏暖暖形象生成：粉色长卷发、粉色蝴蝶结、棕色大眼、粉白衣裙、奶油色斜挎包。公仔采用坐姿 PVC／树脂潮玩质感，包装采用真实纸盒产品图。

- 公仔图集：1536×1024、四列两行，共八款。六种普通款为午后奶茶、薄荷花园、香草烘焙、晚安好梦、蜜桃雨季、海盐书屋；隐藏款为蔷薇花园；限定款为星月礼赞。
- 普通款是日常服装与简单配件；隐藏款增加蔷薇金属王座、蝶翼、王冠与多层蕾丝；限定款增加星绣礼服、透明珠光部件、星星吊饰与月亮水晶底座，造型复杂度有明显差别。
- 包装图集：1536×1024、两列一行，同主题封盒和开盖状态；奶油粉马卡龙色、暖暖人物插画、装饰边框、侧面图鉴与条码。未领取盒共用封盒图，不显示真实奖品。
- 运行时由 `BlindBoxArt.vue` 通过 SVG 裁切视窗引用云端图集，不裁切或缩放原始图片文件。两图 WebP quality 90 / method 6，总计797810字节；逐像素核对 Alpha 不变。
- `manifest.json` 保存原图位置、SHA-256、MD5、图集布局、云端 URL 和远端校验；`prompts.json` 保存生成约束。
- 0～450ms抬起摇盒；450～850ms开盖；850～1300ms撕袋；1300～1900ms亮相落台；1900ms显示基础奖励；2400ms展示限定升级。刷新直接显示已领取结果，不重复派奖。
- 前端类型检查、后端跳过测试的编译及组件视觉核对见项目活动说明。图片和组件核对不代表真实对局或到账验收。

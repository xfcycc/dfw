# 手机游戏操作按钮

为手机玩家生成七枚独立按钮插画，单张透明图集统一画风。底部从左至右为更多、掷骰子、结束行动；更多菜单为我的资产、资产排行、交易、手牌四宫格。

- [云端 WebP 图集](https://pic.caiguoyu.cn/typora/20261017184914633.webp)，1536×1024，254,702 字节。
- 金色掷骰按钮居中放大；绿色更多与珊瑚色结束行动位于两侧。菜单四项分别以房屋、奖杯、交换金币、卡牌表示。
- 原图保留在图像工具生成目录，工作区只保留 URL、元数据及提示词摘要。等尺寸转换 WebP，quality 90 / method 6，不裁切、不缩放，逐像素核对 Alpha 不变。
- `manifest.json` 记录原图摘要、编码参数、七枚按钮的实际坐标，以及远端 HTTP 200、类型、大小、Content-MD5 校验结果。
- `MobileActionArt.vue` 使用同一图集的不同视窗，并限制 SVG 图片范围，防止相邻按钮出现在视窗留白中。
- 仅用于手机操作栏与更多菜单，桌面原按钮图片继续使用原资源。

# 棋盘交互效果逐帧素材

本批沿用已确认的透明、手绘赛璐璐特效风格。运行素材只通过现有 PicGo 图床提供，仓库保存 URL、来源和校验元数据，不保存图片副本。

- 原四类：黑洞、神威、陨星、龙卷风。
- 补充八类：护盾、建筑、冲击、控制、卡背、金币、宝藏、音乐。
- 每类为 4×4、共 16 帧的透明图集，按行播放；WebP 保留原尺寸和透明度。
- `manifest.json` 保存原图路径、生成提示词或摘要、压缩参数、图床地址及 HTTP／大小／MD5 核对结果。
- `coverage.json` 是当前启用配置的机制映射：道具 32、机会 22、财富 14；只代表静态接线范围，不代表逐卡真实对局验收。

前端表现目录位于 `src/web/board-effect-presentation.ts`，演示入口为 `/effects-preview.html`，包含 46 类发动、触发和解除表现。换位、ROOM、地爆天星等位移不绘制连线。

服务端只记录原业务执行前后的公开外观、实际参与者和已有移动顺序，不重新选目标、不重新随机、不执行金额或状态结算。手牌演出不携带具体卡牌和数量，私人事件不写入公开来源卡面。取消、无合法目标或未产生实际拆除时不补造成功事实；护盾抵挡单独展示。

客户端继续使用移动与效果的同一队列，等素材解码及动画结束后才展示后续决策与最终快照；刷新、重连、切后台或减少动态效果时沿用静默同步。生成素材只用于表现，独立演示局面不连接真实房间。

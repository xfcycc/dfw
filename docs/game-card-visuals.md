# 苏暖暖通用卡面

第一版采用机会、财富、道具三类场景，每类包含 R、SR、SSR，共九种样式。角色、插画与右上角斜放的 Q 版稀有度字标沿用确认稿；三类确认图分别保存在 `src/web/public/images/cards/chance.jpg`、`fortune.jpg`、`card.jpg`。

`ContentCard.vue` 使用九个插画视窗展示确认图的对应区域，图内示例正文不参与游戏渲染。名称、事件描述、效果正文和底部小字台词均取自服务端的 `ContentResult`，旧手牌缺省稀有度为 R、名称和规则说明沿用 `ITEMS`。完整卡面随正文增高；手牌缩略图保留插画、名称和简略效果，点击后查看完整卡面。

`CardReveal.vue` 复用现有 Modal，抽卡与出牌共用全屏翻转、光晕、光泽及粒子展示。长卡面在独立区域滚动，继续按钮保持在卡面区域之外；多张补给逐张展示，支持继续、关闭及 Esc。系统启用减少动态效果时保留可读卡面并关闭动画。

验证：Vue / TypeScript 类型检查、后端 compile 和差异格式检查通过。使用真实组件及当前卡池素材查看九款卡面、手牌缩略图、道具揭卡和 390×844 手机尺寸的机会揭卡，并确认继续按钮能关闭卡面。该预览不连接后端，不代表多人联机触发、隐私广播或恢复链路已经运行验收。未执行前端 build、单元测试、冒烟测试或自动提交。

## 样板与素材

| 卡牌身份 | 招式 | 时长 | 表现与固定演示结果 |
| --- | --- | --- | --- |
| `card_naruto_kamui` | 神威 | 3.6 秒 | 旋涡向棋盘内侧展开，建筑副本旋转缩小并卷入，原地显示封印；固定展示停止收租 3 回合 |
| `card_onepunch_serious_punch` | 认真一拳 | 3.4 秒 | 巨拳从施术者一侧蓄势突进，命中停顿、冲击圈和碎屑散开；固定展示目标建筑 3 级降到 0 级 |
| `card_neta_senbonzakura` | 千本樱 | 3.8 秒 | 刀刃出现并淡去，32 片樱刃沿不同弧线散开、汇聚目标并散落；不模拟持续卡业务结算 |
| `card_naruto_reaper_seal` | 尸鬼封尽 | 3.9 秒 | 死神在施术者一侧升起，光带连接双方，封印印记收束；固定展示双方手牌上限各减少 1 |

主体素材由 ImageGen 生成，一张 1254×1254 RGBA PNG，1,359,409 字节，透明通道范围 0～255。四格分别是旋涡、巨拳、刀刃及樱花、死神，未裁切或转码，通过 CSS 选择图集区域。飞散的小花瓣、光带和冲击圈使用简单 SVG/CSS。素材和完整提示词见 `src/web/public/images/ur-spell-preview/manifest.json`。

图集仅保存在本地，没有上传 OSS。为满足本批本地预览要求，`.gitignore` 只为这一张素材增加例外，不改变其他图片的云端存放约定。生成工具实际输出为 1254px，清单记录实际尺寸，CSS 百分比裁切不依赖提示词中的期望尺寸。

## 展示实现

- `ur-spell-preview.ts` 以稳定 `skinId` 登记时长、主题、说明和素材路径，预加载失败清除缓存并显示重试入口。
- `UrSpellPreview.vue` 管理固定局面、选择、预加载、播放、重播、跳过、隐藏卡名和静态演示；更换样板或卸载时使旧加载失效。
- `UrSpellLayer.vue` 接收坐标和目标外观，使用同一时长驱动 CSS 动作和完成通知；卸载清理计时。仅目标副本参与变形，不修改棋盘位置。
- `Board.vue` 新增可选 `effect-overlay` 作用域插槽，暴露既有目标定位函数及棋盘尺寸；正式使用方未传入该插槽，原有表现链路不变。
- 系统 `prefers-reduced-motion` 和「静态演示」共用静态路径，显示一秒提示后展示结果。切后台时结束演出或取消待加载任务，不积压重播。

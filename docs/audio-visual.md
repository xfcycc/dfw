# 游戏音乐、音效与动效

延续页面的奶油色与柔和绿配色，以用户选择的《编织愿景》、相配的原创拨弦/铃音及轻微动作作为反馈。

## 音乐与本机设置

- 首页、大厅、对局和结算统一使用用户提供的《编织愿景》（无限暖暖 / FoldEcho）；按用户说明用于个人聚会娱乐，不标注为 CC0 素材。
- 音乐与音效分别开关、分别调音量；默认音乐 22%、音效 45%，设置存于本机浏览器。
- 首页工具栏和房间页眉的“声音”按钮复用现有 Modal 组件。
- 首次点击或按 Enter/空格启用音频；后台暂停，返回页面恢复；房间断线和历史页暂停音乐。
- 原始 FLAC 转换为 128 kbps AAC / M4A，保留完整约 133 秒曲目，整曲循环；统一使用同一文件，已播放时场景切换不重新开始。素材来源与处理记录见 `src/web/public/audio/LICENSES.md`。

## 游戏反馈

音效现采用十三份本地原创 WAV，替换初版简单振荡器提示音；第一次启用音频时预加载并缓存，后台、静音或超过 250 ms 才加载完成的旧请求不补播。音符以 A、C、D、E、G 为主，点击、移动使用短木质音，聊天、奖励、抽卡和胜利使用轻铃与小幅空间尾音。声音设置提供整套音效试听入口。

参考音频经过 PCM 分析：全曲音高分布推测接近 A 小调，频谱质心中位数约 619 Hz，高于 5 kHz 的能量占比较低。这些是信号分析依据，不等于主观试听或原曲乐器辨认；没有截取原曲片段用于音效。生成脚本为 `scripts/generate-soft-sounds.py`。

| 场景 | 音效与展示 |
| --- | --- |
| 按钮、链接、菜单 | 短点击音 |
| 本人回合 | 两段提示音，同一回合重连不重复；顶部姓名与资产之间显示跳动的 Q 版“你的回合”，遵循减少动态效果偏好 |
| 收到聊天 | 在实时快照收包时播放轻短双铃音，不等待移动展示；首次进入、重连、重复或旧版本、本人发送回显不提示，静音与后台遵循共享音效设置 |
| 掷骰、移动 | 全屏遮罩中央放大播放骰子翻滚换面并定格真实点数，收起后人物逐格跳跃、路径高亮，落点回弹与扩散光圈；配合骰子音和逐格木质短音 |
| 金额变化 | 地块上显示玩家名与正负金额飘字，入账/支出提示音 |
| 购买、建造 | 产权条展开、建筑弹出与柔和光点，独立音阶 |
| 城市事件、私人补给 | 抽卡提示音，事件卡滑入翻转，SR/SSR 短光泽 |
| 主动道具、路障、拆房 | 道具音阶、目标地块光圈 |
| 操作被服务端拒绝 | 轻短错误音，保留原错误提示 |
| 本局结束 | 胜利音阶与三秒淡色彩纸 |

公开反馈比较同局递增版本的服务端快照，首次进入、恢复和重连只建立基线；历史棋盘不触发声音或游戏动画。私人补给只在持有人客户端比较私人状态，不通过公开卡面推断。单次快照优先播放主要事件音，掷骰后的落点提示延后到移动结束附近，避免连续声音叠加。

顶部排名使用 1st～6th 的 Q 版文字插画，和“你的回合”共用 `src/web/public/images/actions/turn-ranks.png` 透明图集，由 `ChibiLettering.vue` 展示对应区域。排名保留与现金、净资产相同的宽高，三项均无底框直接显示；回合文字整体下移 6px，以最多 4px 的纯上下位移跳动，不旋转或缩放。回合提示仅在当前玩家本人在线、对局进行中且未暂停或等待恢复时显示。

掷骰翻滚约 780 ms，结果停留 220 ms，均在覆盖整个视口的遮罩中央展示；开始移动时自动收起遮罩，按服务端 `motion.path` 每格 190 ms 播放，落地反馈约 500 ms。移动期间底部轻提示显示行动者、点数、移动进度和落点；路障截停、后退、绕过起点均沿实际路径展示，不按骰子点数自行推算位置。金额、地块反馈在落地后展示，抽卡弹窗等本轮移动展示结束后出现。

客户端将移动路径与结算展示分开：先播放掷骰、逐格移动及 500 ms 落地停顿，再同步现金、地产、排行榜、手牌、状态和公开记录，展示金额、地块及结算声音。机会/财富事件、经过起点的私人补给先揭卡，收起卡面后再打开购买、升级、租金/费用防御或事件选择、手牌超限整理等本人待办弹窗。入狱、路障消除、破产和胜负结果也随结算快照展示。

同次结算包含事件再次移动时，按服务端 `motion.segments` 分段播放：掷骰及第一段移动 → 机会/财富格落地停顿 → 揭示事件卡 → 收起卡面 → 前进/后退的事件路径 → 最终落地停顿 → 结算及待办弹窗。事件移动不重复掷骰，路径包含真实路障截停位置。跨手牌整理等选择恢复时，仍先展示未揭示的触发事件，再继续其移动；卡面按事件身份去重。旧快照没有分段数据时沿用原单路径。

服务端照常结算，客户端移动期间禁用游戏操作，聊天使用最新收到的服务端版本。连续收到的公开和私人快照按收包顺序排队，下一条路径等待前一条落地；实时记录接口返回的较新版本暂不显示，避免提前播报。断线、身份切换或切到后台时直接同步已收到的最新局面，不补播积压动画与卡面；离开组件清理定时器和监听。遵循系统减少动态效果偏好：跳过掷骰和逐格动画，直接显示结算及可读状态。

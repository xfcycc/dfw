### 已复现问题与修复

跨响应式断点时，经典桌面页面缩到 390×844 后出现 Vue 组件更新异常，包含 `Cannot read properties of null (reading 'emitsOptions')` 和 `Cannot set properties of null (setting '__vnode')`，页面仍停留旧组织方式，手机更多入口缺失，后续点击不再正常更新；刷新后恢复。真实组件回归测试在原实现上复现 `insertBefore`／`__vnode`／`emitsOptions` 异常。原因是移动状态与揭卡 Teleport 的目标容器随条件销毁／创建；将两个目标容器改为 `v-show`，与既有 `room-dashboard` 一样持续挂载，避免子组件向已移除或尚未存在的目标移动，不重建房间或清空选择。

# 道具卡库

> 2026-10-13 评审：本库共 111 张，12 类模板为首版卡池口径；新增遥控骰子允许自选 1～6 点，原 110 张效果保留，指定传送到无主地产的每局唯一传送门暂缓。本库尚未全部实现。金额为基准值，默认新局 ×2；手牌上限 6 张，超限由本人选择保留六张，其余每张基准 200 折现，每回合最多一张主动卡。主动前进／后退 N 格替代本次掷骰，结算后进入管理；掷骰加码在掷骰前使用，占一次主动出牌，与骰子合成一次连续移动，只结算最终落点。免费升级无合法目标、抢夺目标没牌时，保留卡且不占主动次数；抢夺由服务端从所选未破产对手手牌随机转移 1 张，双方不查看其余手牌。解控在监禁／休息被施加时响应，可使用或放弃，不占主动次数、不补走已跳过的回合。付款减免只覆盖强制费用，每笔至多一种防御，减免额向下取整，先减免再资产抵债，房东只收减免后金额。机制与完整参数组合确定后，匹配皮肤按 R／SR／SSR = 6／3／1 加权，条目数量与稀有度分布不是机制概率。规则以 [评审主稿](../game-content-design.md) 为准。

大富翁联机模式的道具卡库共 111 张，覆盖 12 种效果模板与四类激活方式，出处来自游戏、动漫、小说、影视、网络梗与中华文化，玩家可用它们在掷骰、收租、被送入监狱等时机主动干预局势。“持续”“即时”是卡面标签：加码仍占主动次数，解控响应不占主动次数。

卡面阅读顺序为「名称＋稀有度 → 台词 → 描述 → 效果」。台词和描述为吐槽、热梗与题材二次创作，出处仅作题材参考，不表示原作原句。R／SR／SSR 为皮肤稀有度，UR 仅预留，暂无条目、不进入抽取；稀有度不代表正收益或强度承诺。效果栏保留原规则与基准数值，实际展示应使用本局倍率及固定覆盖后的金额。

## 已确认的抽取与响应规则（待实现）

单张随机道具的机制概率：替代掷骰 18%（固定步数 14%、遥控骰子 4%）、路障 8%、拆房 8%、换位 8%、免租 12%、主动位移 10%、加码 6%、免费升级 10%、付款减半 8%、解控 5%、抢夺 3%、即时现金 4%，合计 100%。14% 与 4% 均为总卡池概率，不能再乘一次 18%；定向补给只抽指定类型，不重新抽整池机制。

遥控骰子与固定步数卡都属于替代掷骰模板，但参数类型不同；固定步数皮肤不能让玩家自选点数。固定步数 0／2／3／4／5／6、主动位移 −3／−2／+2／+3／+4、加码 +1／+2／+3、即时现金基准 300／500／800，各自在所属机制内按去重参数等概率抽取；遥控在使用时自选 1～6 点。机制和完整参数组合确定后，在匹配皮肤内按 R／SR／SSR = 6／3／1 加权，不承诺总出货比例为 5:3:2；不能把素材张数直接作为参数概率。

九张抢夺皮肤统一由服务端随机转移一张牌，公共日志不展示被抢牌型、数量或具体卡面；双方只看到被转移的牌，不查看对方其余手牌。掷骰加码在掷骰前使用并占主动次数，骰子与加码合并连续移动，经过起点和路障照常处理，只结算最终落点；九张解控皮肤在状态施加时选择使用或放弃，不占主动次数，不补走已经跳过的回合。

超限时本人从原有与本次新牌中选留恰好六张，其余逐张按基准 200 折现；已有超限手牌同样由本人选留，不自动删除或折现，选择完成前暂停后续效果。候选、随机结果与返回位置保存，重连或重启不重新抽牌、不重复折现。付款减免的减免额向下取整，欠 301 时减 150、付 151；先锁定防御后的债务，再协商抵债。完整选择窗口要求见 [主稿第 7 章](../game-content-design.md#7-道具卡的确认规则)，均待实现。

免费升级卡确认前取消选地，或确实无合法目标时，保留原卡、不消耗、不占主动次数，也不折成现金。确认成功所得建筑与普通建筑按本局标准建造成本估值，出售、整体抵押、净资产和灾害损失／补偿使用相同口径；免费只免去升级支付，不把建筑价值记为零。固定金额覆盖及抵押建筑不可单独出售等既有规则沿用，具体机制仍待接入。

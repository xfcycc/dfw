# 四角活动轮换与多人游园会

2026-10-15。起点和监狱固定，两个新活动角共用五玩法池。只对新开对局生成活动地图，旧地图、旧存档缺失活动字段时不迁移。

## 轮换与地图

开局人数×5个完整结束的全局回合换一期，中途破产不改周期，休息跳过计数；活动内部操作不推进正常回合。当前和下期各两个不同玩法，五项洗牌队列持久化，各角不连续保持相同玩法。剩余3、2、1回合时将下期两个活动角预告写入“城市新鲜事”公开记录，棋盘中央不再显示轮换条；角落倒计时保留。全部落点、活动、费用和交易结束后，在正常回合结束事务中换图；客户端翻转中点替换图案，整个展示约1.2秒。站在格上不因轮换再触发。

原角上的机会和财富各移一个到边上，特殊格总数和间隔保留，地产减少两块。活动角仅落点触发，路障截停和事件位移继续使用原结算入口。

## 金额与规则

以下是倍率2的最终值，实际通过一倍基准在开局冻结到活动快照，后续不重复乘倍率。

| 活动 | 参与与结算 |
| --- | --- |
| 赌场 | 踩中者自愿。500猜大小（1～3小，4～6大），猜中总到账1000；1000猜单个点数，猜中总到账3000。先扣本金，未中不返款。娱乐骰不移动棋子。 |
| 赛马 | 全部未破产玩家分别选一匹或放弃，下注500，八匹等胜率，公开选马，可多人押同一匹，中奖各总到账5000。全员放弃不开赛，比赛展示约8秒。 |
| 轮盘 | 踩中者可放弃，或指定另一未破产玩家，指定后必须应战。随机先手、六弹巢一颗子弹、不重新转弹巢，最多六次。败者产生2000玩家费用，保留既有自动免单、适用减半、防御选择、抵押、抵债和清算；免租卡仅租金可用。 |
| 红包 | 所有未破产玩家领取，不扣现金，银行基础总额人数×500。按人数生成满足总和及1%～90%范围的整数份额，随机分配到玩家，与领取速度无关。每人独立10%再得本人基础份额，最终两倍，额外奖由银行发放。两人局基础份额实际10%～90%。 |
| 猜拳 | 全场秘密提交。0石头、1剪刀、2布；仅两种手势时淘汰败方，一种或三种平局重来。直到一人独得2000，不收参与费，不设轮数上限。 |

监禁、休息玩家仍参与全场活动，破产玩家和观战者只看。自愿下注只能使用已有现金。输入不设超时；必需参与者离线时等待重连。房主移出参与者时，未经济结算活动退本金中止；已产生的轮盘费用继续沿用原结算。

## 状态与接口

`Room.activityRotation` 保存周期、已结束回合、轮换版本、当前及下期活动、内部洗牌队列、最终金额；`Room.activity` 保存独立活动实例、阶段、子轮次、参与者、已提交选择、随机结果、下注、奖励和自动展示截止时间。

WebSocket沿用原命令信封，新增 `activityInput`：`activityId`、`activityRound`，及可选的 `selection`、`point`、`playerId`。赌场selection为0放弃、1大小、2点数；赛马0放弃、1～8选马；轮盘0放弃、1指定或开枪；红包1领取；猜拳0～2手势。

活动输入允许同一阶段内较旧房间版本，但仍严格校验活动身份、子轮次、参与身份、现金与未提交状态；未来版本拒绝。其他命令不放宽版本校验。复用房间锁、事务和命令回执，输入不直接写库，不逐玩家查询。

公开活动VO显式排除子弹位置、未揭晓赛果和秘密手势；本人私有投影提供自己的选择。红包基础份额及幸运结果只在统一揭晓后公开。公开日志仅在实际揭晓时记录手势和获奖，内部审计保持原有权限边界。

活动暂停父效果队列，只有费用恢复效果可优先插入。轮盘产生费用后保留父活动，直到付款、交易抵债或清算完成才结束；活动结束后先恢复原剩余效果，再恢复正常操作。自动展示按持久化服务端截止时间推进，客户端无权决定随机结果或派奖。

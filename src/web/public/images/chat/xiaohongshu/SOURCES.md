# 小红书聊天表情

本目录收录 61 个小红书表情，从原始 520 × 520 PNG 动图等比缩小为 96 × 96 WebP，保留透明背景、动画帧和播放时长。

- 收集来源：Augenstern-O / Stickers，https://github.com/Augenstern-O/Stickers/tree/91285989c50eaf45560dab02043df1d4b03aded1/RedNote
- 固定版本：`91285989c50eaf45560dab02043df1d4b03aded1`
- 名称和顺序：同版本 `OwO.json` 的「小红书」分组。
- 收集仓库标注的许可：CC BY 4.0，https://creativecommons.org/licenses/by/4.0/
- 原始表情设计来自小红书，收集仓库的许可声明不等于原始图案版权授权。

聊天以 `[小红书:名称]` 保存代码，房间、局内和历史记录统一渲染。本地托管图片，在进入房间时预加载，避免回顾记录依赖外部 CDN。
